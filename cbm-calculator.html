CBM 계산기

박스별 실측 규격과 수량으로 총 CBM과 참고 부피중량을 계산합니다. 항공사별 환산계수는 실제 운송사 기준을 적용하세요.

CBM부피중량모바일 계산
KBRIDGE LOGISTICS TOOLCBM 계산기
페이지 내 바로 조회
산식 기준 업데이트CBM은 실측 규격 기준이며 항공 부피중량 환산계수는 항공사·서비스별로 달라질 수 있습니다.
기준일 2026.07.07

화물 규격 입력

박스별 최종 포장 규격, 중량과 수량을 입력하면 각 행과 전체 결과가 자동 계산됩니다.

01다중 화물 입력서로 다른 규격을 행으로 추가해 합산합니다.
02단위 자동 변환mm·cm·m·inch를 CBM으로 변환합니다.
03적재 가능성 확인컨테이너 내부와 도어 규격을 비교합니다.
가로 (Length) 세로 (Width) 높이 (Height) 단위 중량 (kg) 수량 개당 CBM 합계 CBM 삭제

최종 포장 상태의 외형 치수와 개당 실중량을 입력하세요. 수량과 단위를 변경하면 결과가 즉시 다시 계산됩니다.

계산 요약

총 부피, 총 수량, 실중량, 항공 산출중량과 해상 W/M을 한눈에 확인합니다.

컨테이너 용적 대비 적재율

총 CBM과 개별 화물 치수를 기준으로 용적 초과, 내부 적재와 도어 통과 여부를 함께 확인합니다.

입력 대기

컨테이너 규격·도어 통과 확인

대표 내부 규격과 입력 화물의 통과 가능성을 컨테이너별로 비교합니다.

규격 높이 Tare Payload Max Gross Door W×H 내부 L×W×H 용적 도어·내부 확인
컨테이너 규격은 선사·장비·제조사별로 일부 차이가 있습니다. 계산 결과는 대표 제원 기준의 참고값이며 실제 적재 가능 여부는 팔레트, 포장 돌출, 고박, 중량 배분과 현장 작업성을 함께 확인해야 합니다.
