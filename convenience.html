견적 전

화물 기본정보 준비

품목명, HS CODE 후보, 박스 규격, 중량과 수량을 먼저 정리하면 견적 검토가 빨라집니다.

01HS CODE와 품목 특성 확인
02CBM·중량·박스 수량 계산
03출발지·도착지·희망일 정리
일정 확정 전

국가별 일정과 비용 확인

01도착국 공휴일 확인

03인코텀즈와 비용 부담 확인
