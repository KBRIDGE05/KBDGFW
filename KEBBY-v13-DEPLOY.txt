KBRIDGE 케비 v13 / Worker v12 배포 안내

이번 버전의 핵심
- 단순 서비스·블로그 질문은 웹사이트 자체의 38개 페이지 디렉터리에서 즉시 답변합니다.
- Worker가 이전 버전이거나 장문·미완성 답변을 반환해도 프런트에서 짧은 완결 답변으로 교정합니다.
- 관련 블로그·서비스 페이지 제목과 클릭 링크를 반드시 함께 표시합니다.
- 인보이스·패킹리스트 질문은 AI 장문 생성 없이 고정된 짧은 답변을 제공합니다.

배포 순서
1. Cloudflare Worker
   kbridge-ai-chat-worker-fast-v12.js 전체 내용을 현재 사이트가 연결된 Worker에 배포합니다.
   Worker 기본 URL을 열었을 때 version이 "v12",
   responseMode이 "concise-links-local-guard-v12"인지 확인합니다.

2. 웹사이트
   KBDGFW-main-Kebby-final-v13 폴더의 전체 파일을 기존 사이트에 덮어씁니다.
   assets/kebby-chat.js와 assets/kebby-site-directory-v13.json이 반드시 포함되어야 합니다.
   전체 HTML 38개의 캐시 버전은 20260728-chat-v13입니다.

3. 확인
   케비의 대화를 초기화한 뒤 "인보이스"를 입력합니다.
   두 문장 핵심 설명과
   "커머셜 인보이스 작성방법 & 양식 다운로드" 링크가 표시되어야 정상입니다.

중요
- 이번 버전은 "인보이스" 같은 단순 질문을 Worker로 보내지 않고 브라우저에서 바로 처리합니다.
- 따라서 Cloudflare Worker 캐시나 배포 지연이 있어도 이전처럼 장문이 잘려 표시되지 않습니다.
